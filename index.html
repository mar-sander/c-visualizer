            Ver.0.7_0813では、int変数、代入・再代入、整数の + - * / %、比較、printf、main直下の単純なscanf、if・if〜else、return 0;、main直下やforで使う単独の ++ / -- / += / -=、基本的なforに対応しています。for本体ではif・if〜elseも使用でき、ifは最大2階層まで扱えます。
forでは宣言済みのint変数を使い、初期化・条件・更新を書いて、本体を波かっこで囲んでください。forヘッダ内の変数宣言・省略形・複数式、入れ子for、for内scanfは現在未対応です。
7反復以上では教材用の説明表示だけを一部省略します。実際の処理・printf出力・変数更新はすべて行います。また、1つのforにつき500反復をVisualizer独自の安全上限としています。これはC言語自体の制限ではありません。
else if、3階層以上のif、波かっこ省略、次行に開き波かっこを書く形式、while、switch、配列、ユーザー定義関数などは現在未対応です。開き波かっこはif・else・forと同じ行に書き、1つの文ごとに改行してください。
