# C Code Visualizer

C Code Visualizer は、C言語初学者向けに、コードの処理過程・変数の変化・出力結果を見える化する学習支援ツールです。

このツールは、C言語を完全に実行するオンラインコンパイラではありません。  
学習者が「コードをどの順番で読み、変数の中身がどう変化し、何が画面に表示されるのか」を理解することを目的としています。

## 公開ページ

GitHub Pages で公開しています。

公開URL: https://mar-sander.github.io/c-visualizer/

## 使い方

1. コード入力欄にC言語のコードを入力する
2. 「可視化する」ボタンを押す
3. 実行結果、変数の状態、実行の流れ、コードと説明を確認する

## 対応するif文と入れ子ifの形式

開き波かっこをif行・else行と同じ行に書く、次の形式に対応しています。

```c
if(条件){
    処理;
}else{
    条件が成立しなかったときの処理;
}
```

内側ifは、外側のif側またはelse側へ置けます。

```c
if(外側の条件){
    処理;

    if(内側の条件){
        処理;
    }

    処理;
}
```

階層は、main関数内に直接書かれたifまたはif〜elseを1階層目、その中にあるifを2階層目として数えます。3階層目以降には対応していません。

対応には次の制限があります。

- elseは省略可能
- `}else{`と、`}`の次の行に`else{`を書く形に対応
- 内側ifにelseを付ける形は未対応
- else ifは未対応
- 3階層以上のifは未対応
- 開き波かっこはif行・else行と同じ行
- if側の閉じ波かっこは、`else{`と同じ行または単独行
- if〜else文全体の最後の閉じ波かっこは単独行
- 外側・内側の分岐内で実行できるのは、既存変数への代入とprintf
- 分岐内での新しい変数宣言は未対応
- 波かっこなしif文は未対応
- 1つの文ごとに改行が必要

## 入れ子ifの安全な扱い

- 選択されなかった外側分岐の内側条件は評価せず、未宣言・未初期化の変数があっても警告しない
- 選択された内側条件を評価できない場合は、内側本文だけを停止し、外側ブロック内の後続処理を続ける
- 3階層以上、内側ifへのelse、入れ子内の未対応制御構文を検出した場合は、外側分岐を部分実行せず安全に停止する
- コメントやprintf文字列内の`if`、`else`、`{`、`}`は構造判定に使用しない

## 入力時の注意

Ver.0.4_0810では、1つの文ごとに改行して入力してください。

例：

```c
int a = 3;
int b = 5;
int c = a + b;
printf("%d\n", c);
```

1行に複数の文がある場合は、次の警告を表示します。

「1行に複数の文があります。文の終わりで改行してください。」
