# C Code Visualizer

C Code Visualizer は、情報技術検定2級程度のC言語初学者向けに、コードの処理過程・変数の変化・条件分岐・出力結果を見える化する学習支援ツールです。

このツールは、C言語を完全に実行するオンラインコンパイラではありません。  
学習者が「コードをどの順番で読み、変数の中身がどう変化し、何が画面に表示されるのか」を理解することを目的としています。

## 公開ページ

GitHub Pages で公開しています。

公開URL: https://mar-sander.github.io/c-visualizer/

## 使い方

1. コード入力欄にC言語のコードを入力する
2. scanfを使う場合は、専用入力欄へ値を1行ずつ入力する
3. 「可視化する」ボタンを押す
4. 実行結果、変数の状態、実行の流れ、コードと説明を確認する

## scanfによる整数入力

次の形で、宣言済みのint型変数へ整数を1つ入力できます。

```c
int score;
scanf("%d", &score);
```

- 対応する書式指定子は `%d` のみ
- 一度のscanfで入力できる変数は1つだけ
- scanfはmain直下に記述し、分岐内では使用しない
- 入力値は画面上の「入力値（scanf用）」へ1行ずつ入力
- scanfが複数ある場合は、入力値を上から順に1行ずつ使用
- 入力不足、不正な整数、未宣言変数、未対応形式では、その行で安全に停止
- エラー前までの変数値と出力は保持

`&変数`は上記のscanf構文としてだけ認識します。一般的なアドレス演算子やポインタ処理には対応していません。

## 対応するif文と入れ子if・if〜elseの形式

開き波かっこをif行・else行と同じ行に書く、次の形式に対応しています。

```c
if(条件){
    処理;
}else{
    条件が成立しなかったときの処理;
}
```

内側if・if〜elseは、外側のif側またはelse側へ置けます。

```c
if(外側の条件){
    処理;

    if(内側の条件){
        処理;
    }else{
        条件が成立しなかったときの処理;
    }

    処理;
}
```

階層は、main関数内に直接書かれたifまたはif〜elseを1階層目、その中にあるifまたはif〜elseを2階層目として数えます。3階層目以降には対応していません。

対応には次の制限があります。

- elseは省略可能
- 1階層目・2階層目とも、`else`は1つだけ使用可能
- 1階層目・2階層目とも、`}else{`と、`}`の次の行に`else{`を書く形に対応
- else ifは未対応
- 3階層以上のifは未対応
- 開き波かっこはif行・else行と同じ行
- if側の閉じ波かっこは、`else{`と同じ行または単独行
- if〜else文全体の最後の閉じ波かっこは単独行
- 外側・内側の分岐内で実行できるのは、既存変数への代入とprintf
- 分岐内での新しい変数宣言は未対応
- 波かっこなしif文は未対応
- 1つの文ごとに改行が必要

## 入れ子if・if〜elseの安全な扱い

- 内側条件が成立した場合はif側だけ、不成立の場合はelse側だけを実行する
- 選択されなかった外側分岐の内側条件は評価せず、未宣言・未初期化の変数があっても警告しない
- 選択された内側条件を評価できない場合は、内側のif側・else側をどちらも実行せず、外側ブロック内の後続処理を続ける
- 外側if〜else全体の構造検査を外側条件の評価前に行う
- 未選択側を含め、3階層以上、else if、入れ子内の未対応制御構文などを検出した場合は、外側構造を部分実行せず安全に停止する
- コメントやprintf文字列内の`if`、`else`、`{`、`}`は構造判定に使用しない

## 非対応

- else if
- 3階層以上のif
- 分岐内での新しい変数宣言
- 波かっこなしif文
- 開き波かっこを次の行に書くif文
- 開き波かっこを次の行に書くelse文
- 論理演算子（`&&`、`||`、`!`）
- scanfの `%d` 以外（`%f`、`%lf`、`%c`、`%s` など）
- scanfで複数変数を一度に入力する形式
- 分岐内のscanf
- float、char、文字列、配列への入力
- scanfの戻り値を使う処理
- 一般的なポインタ処理
- 対話型コンソールと、scanfを含む完全なC言語実行
- for文
- while文
- switch文
- 配列
- ユーザー定義関数
- 構造体
- ファイル入出力
- 複数ファイル
- 本物のコンパイルエラー再現

## 入力時の注意

Ver.0.6_0812では、1つの文ごとに改行して入力してください。

例：

```c
int a = 3;
int b = 5;
int c = a + b;
printf("%d\n", c);
```

1行に複数の文がある場合は、次の警告を表示します。

「1行に複数の文があります。文の終わりで改行してください。」
