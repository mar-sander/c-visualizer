# C Code Visualizer

C Code Visualizer は、情報技術検定2級程度のC言語初学者向けに、コードの処理過程・変数の変化・条件分岐・出力結果を見える化する学習支援ツールです。

このツールは、C言語を完全に実行するオンラインコンパイラではありません。  
学習者が「コードをどの順番で読み、変数の中身がどう変化し、何が画面に表示されるのか」を理解することを目的としています。

## 公開ページ

GitHub Pages で公開しています。

公開URL: https://mar-sander.github.io/c-visualizer/

## 使い方

1. コード入力欄にC言語のコードを入力する
2. scanfを使う場合は、専用入力欄へ値を1行ずつ入力する
3. 「可視化する」ボタンを押す
4. 実行結果、変数の状態、実行の流れ、コードと説明を確認する

## scanfによる整数入力

次の形で、宣言済みのint型変数へ整数を1つ入力できます。

```c
int score;
scanf("%d", &score);
```

- 対応する書式指定子は `%d` のみ
- 一度のscanfで入力できる変数は1つだけ
- scanfはmain直下に記述し、分岐内では使用しない
- 入力値は画面上の「入力値（scanf用）」へ1行ずつ入力
- scanfが複数ある場合は、入力値を上から順に1行ずつ使用
- 入力不足、不正な整数、未宣言変数、未対応形式では、その行で安全に停止
- エラー前までの変数値と出力は保持

`&変数`は上記のscanf構文としてだけ認識します。一般的なアドレス演算子やポインタ処理には対応していません。

## 対応するif文と入れ子if・if〜elseの形式

開き波かっこをif行・else行と同じ行に書く、次の形式に対応しています。

```c
if(条件){
    処理;
}else{
    条件が成立しなかったときの処理;
}
```

内側if・if〜elseは、外側のif側またはelse側へ置けます。

```c
if(外側の条件){
    処理;

    if(内側の条件){
        処理;
    }else{
        条件が成立しなかったときの処理;
    }

    処理;
}
```

階層は、main関数内またはfor本体内に直接書かれたif・if〜elseを1階層目、その中にあるif・if〜elseを2階層目として数えます。for文自体はifの深度に数えません。3階層目以降には対応していません。

対応には次の制限があります。

- elseは省略可能
- 1階層目・2階層目とも、`else`は1つだけ使用可能
- 1階層目・2階層目とも、`}else{`と、`}`の次の行に`else{`を書く形に対応
- else ifは未対応
- 3階層以上のifは未対応
- 開き波かっこはif行・else行と同じ行
- if側の閉じ波かっこは、`else{`と同じ行または単独行
- if〜else文全体の最後の閉じ波かっこは単独行
- 外側・内側の分岐内で実行できるのは、既存変数への通常代入、printf、`return 0;`
- 分岐内の `++`、`--`、`+=`、`-=` は未対応
- 分岐内での新しい変数宣言は未対応
- 分岐内のscanfは未対応
- 波かっこなしif文は未対応
- 1つの文ごとに改行が必要

## 入れ子if・if〜elseの安全な扱い

- 内側条件が成立した場合はif側だけ、不成立の場合はelse側だけを実行する
- 選択されなかった外側分岐の内側条件は評価せず、未宣言・未初期化の変数があっても警告しない
- 選択された内側条件を評価できない場合は、内側のif側・else側をどちらも実行せず、外側ブロック内の後続処理を続ける
- 外側if〜else全体の構造検査を外側条件の評価前に行う
- 未選択側を含め、3階層以上、else if、入れ子内の未対応制御構文などを検出した場合は、外側構造を部分実行せず安全に停止する
- コメントやprintf文字列内の`if`、`else`、`{`、`}`は構造判定に使用しない

main直下のifで条件を評価できない場合は、そのifの対象処理を実行せず後続へ進みます。for内ifで、実際に評価・実行した条件や文に実行時エラーが起きた場合は、次の反復へ進まずプログラムを停止します。

## 対応するfor文の形式

main関数の本体へ直接置く基本形と、for本体へ直接forを置く入れ子に対応しています。

```c
int i;

for(i = 0; i < 5; i++){
    printf("%d\n", i);
}
```

2重forは、次のように書けます。さらに内側forの本体へ直接もう1つforを置く3重forまで対応します。

```c
int i;
int j;

for(i = 1; i <= 3; i++){
    for(j = 1; j <= i; j++){
        printf("*");
    }
    printf("\n");
}
```

- 初期化では、宣言済みのint型変数へ値を代入する
- 条件には、既存の整数式・比較式と0／非0による真偽判定を使用できる
- 更新には、単独の `++`、`--`、整数定数による `+=`、`-=`、または通常代入を使用できる
- for本体には、既存変数への代入、単独更新文、printf、`return 0;`、対応範囲内のif・if〜elseを置ける
- for本体には複数文を置くことができ、空本体も使用できる
- for本体でループ変数を変更した場合も、本体の処理後に更新式を実行する
- main直下のscanfで取得したint値を、後続forやfor内ifの条件から参照できる
- main直下に複数の独立したfor文を置ける
- for本体へ複数の兄弟forを直接置くことができる
- main直下のforを1階層目として、直接的な入れ子を最大3階層まで扱う
- 開き波かっこはforヘッダと同じ行に書き、本体を波かっこで囲む

for本体では、単純なif・if〜else、同一for内の複数if、最大2階層のifを使用できます。for自体はif深度に数えないため、次の形はif深度2として対応範囲です。

```c
for(i = 0; i < 5; i++){
    if(i > 0){
        if(i % 2 == 0){
            printf("%d\n", i);
        }
    }
}
```

for本体の構造は、入れ子for、0反復になるfor、選択されないif・else側も含めて、最外側forの初期化前に全体を検査します。未対応構造を含むforを途中まで実行することはありません。コメントやprintf文字列内の`for`、`{`、`}`は入れ子の構造判定に使用しません。

対応するのは、for本体へ直接forを置く形です。4階層以上のfor、if・else分岐内のfor、for内ifの分岐内へさらにforを置く形（for→if→for）、for内scanfには対応していません。

## for文の反復説明表示

- 単独forは従来どおり、入れ子forは外側for・内側for・最奥forとして表示する
- 子forの表示上の反復番号は、親forから呼び出されるたびに1から始める
- 各forの1回の呼び出しにつき、0～6反復では各反復の説明をすべて表示する
- 7反復以上では、先頭3反復、中略、実際の最終反復、終了理由を表示する
- 親forで省略された反復内の子・孫for説明も一緒に省略し、残された反復内では子・孫forを同じ規則で圧縮する
- 省略するのは教材用の説明表示だけで、条件判定・本体・更新は通常どおり実行する
- printfの出力結果と最終的な変数状態は省略・変更しない
- return、実行時エラー、安全上限で終了した場合は、実際に終了原因が発生した反復と、その地点へ至る親子forの経路を残す

表示上の局所反復番号と、次項の安全上限で使う可視化全体の累計回数は別に管理します。

## for文の安全上限

ブラウザの停止を防ぐため、ソースコード上の各for文について、可視化1回全体で本体へ入る回数を累計500回までに制限しています。同じ子forが親forから何度も呼び出される場合も、その子forの回数は可視化全体で累計します。

例えば、外側forが10回実行され、そのたびに同じ内側forが3回実行される場合、内側forの累計は30回です。兄弟forや別のソース上forは、それぞれ独立したカウンタを持ちます。

- 500回目の本体と更新までは実行する
- その後にもう一度条件を判定する
- 条件が偽なら500反復で正常終了する
- 条件が真で501回目の本体へ進む必要がある場合は、その本体と更新を実行せず安全停止する
- 安全停止後は親forやmainの後続処理へ進まない

これはC言語自体の反復回数制限ではなく、Visualizerをブラウザ上で安全に動かすための独自制限です。

## 非対応

### if・制御構造

- else if、3階層以上のif
- if・else・forの波かっこ省略と、開き波かっこを次の行へ置く形式
- if分岐内の `++`、`--`、`+=`、`-=`、scanf、変数宣言
- while、do while、switch、break、continue
- 4階層以上のfor、if・else分岐内のfor、for→if→for、for内scanf

### forヘッダ・for本体

- `for(int i = 0; ... )` のようなforヘッダ内変数宣言
- `for(;;)`、初期化・条件・更新の省略
- forヘッダ内の複数式、カンマ演算子
- `i += step` のように変数を右辺へ使う複合代入
- for本体での変数宣言

### 式・入出力・データ

- 論理演算子（`&&`、`||`、`!`）
- 代入式・printf引数など、式中で評価値や副作用を利用する `++`、`--`
- printfの `%%`
- scanfの `%d` 以外（`%f`、`%lf`、`%c`、`%s` など）
- scanfで複数変数を一度に入力する形式と、scanfの戻り値を使う処理
- float、char、文字列変数、配列、一般的なポインタ処理、構造体
- 対話型コンソールと、scanfを含む完全なC言語実行

### プログラム構成

- ユーザー定義関数、ファイル入出力、複数ファイル
- 本物のコンパイルと、コンパイラと同一のエラー再現

else if、波かっこ省略、次行に開き波かっこを書く形式、forヘッダ内変数宣言、`for(;;)`、while、配列、4階層以上のfor、if内forなどは、C言語として有効でも現在のVisualizerでは未対応です。Visualizerの警告を、C言語そのものの構文エラー判定として使用しないでください。

## 入力時の注意

Ver.0.8_0818では、1つの文ごとに改行して入力してください。

例：

```c
int a = 3;
int b = 5;
int c = a + b;
printf("%d\n", c);
```

1行に複数の文がある場合は、次の警告を表示します。

「1行に複数の文があります。文の終わりで改行してください。」
