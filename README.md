# C Code Visualizer

C Code Visualizer は、C言語初学者向けに、コードの処理過程・変数の変化・出力結果を見える化する学習支援ツールです。

このツールは、C言語を完全に実行するオンラインコンパイラではありません。  
学習者が「コードをどの順番で読み、変数の中身がどう変化し、何が画面に表示されるのか」を理解することを目的としています。

## 公開ページ

GitHub Pages で公開しています。

公開URL: https://mar-sander.github.io/c-visualizer/

## 使い方

1. コード入力欄にC言語のコードを入力する
2. 「可視化する」ボタンを押す
3. 実行結果、変数の状態、実行の流れ、コードと説明を確認する

## 対応範囲 Ver.0.1

- int型の変数宣言
- int型の初期化
- 代入
- 整数の四則演算
- printf による表示
- 上から順番に実行されるコードの可視化

## 非対応

- if文
- for文
- while文
- 配列
- 関数
- ポインタ
- scanf
- 複数ファイル
- 本物のコンパイルエラー再現

## 入力時の注意

Ver.0.1では、1つの文ごとに改行して入力してください。

例：

int a = 3;
int b = 5;
int c = a + b;
printf("%d\n", c);
