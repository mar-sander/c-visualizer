# C Code Visualizer

C Code Visualizer は、C言語初学者向けに、コードの処理過程・変数の変化・出力結果を見える化する学習支援ツールです。

このツールは、C言語を完全に実行するオンラインコンパイラではありません。  
学習者が「コードをどの順番で読み、変数の中身がどう変化し、何が画面に表示されるのか」を理解することを目的としています。

## 公開ページ

GitHub Pages で公開しています。

公開URL: https://mar-sander.github.io/c-visualizer/

## 使い方

1. コード入力欄にC言語のコードを入力する
2. 「可視化する」ボタンを押す
3. 実行結果、変数の状態、実行の流れ、コードと説明を確認する

## 対応範囲 Ver.0.2_0730

更新日：2026-07-30

- int型の変数宣言
- 値を入れないint型変数の宣言と未初期化表示
- int型変数の初期化
- 既存変数への代入・再代入
- 整数の四則演算
- 比較演算子（`<`、`<=`、`>`、`>=`、`==`、`!=`）
- 比較結果をC言語と同じ1（成立）または0（不成立）として扱う
- printf による表示
- 単純なif文
- if文の条件式は、結果が0なら不成立、0以外なら成立として扱う
- 複数の独立した単純if文
- 上から順番に実行されるコードの可視化
- 行ごとの説明
- 変数状態と出力結果の表示

## 対応するif文の形式

次のように、開き波かっこをif行と同じ行に、閉じ波かっこを単独行に書く形式に対応しています。

```c
if(条件){
    処理;
}
```

対応には次の制限があります。

- elseなし
- if文の入れ子なし
- 開き波かっこはif行と同じ行
- 閉じ波かっこは単独行
- if文内で実行できるのは、既存変数への代入とprintf
- if文内での新しい変数宣言は未対応
- 波かっこなしif文は未対応

## 非対応

- else
- else if
- 入れ子のif文
- if文内での新しい変数宣言
- 波かっこなしif文
- 開き波かっこを次の行に書くif文
- for文
- while文
- 配列
- ユーザー定義関数
- ポインタ
- scanf
- 構造体
- ファイル入出力
- 複数ファイル
- 本物のコンパイルエラー再現

## 入力時の注意

Ver.0.2_0730では、1つの文ごとに改行して入力してください。

例：

```c
int a = 3;
int b = 5;
int c = a + b;
printf("%d\n", c);
```

1行に複数の文がある場合は、次の警告を表示します。

「1行に複数の文があります。文の終わりで改行してください。」
